# Matriz de Trazabilidad Contractual Frontend ↔ Backend (82 Endpoints)

**Proyecto:** FindJob Colombia Marketplace System  
**Documento:** `frontend/FRONTEND_CONTRACT_MATRIX.md`  
**Fecha:** 2026-11-03  
**Alcance:** 82 Endpoints oficiales expuestos por FastAPI (`backend/app/api/v1/`) y contrastados con el Frontend Next.js y evidencias Stitch (`modules_summary.json` / `uxmapping_v1.pdf`).

---

## Convenciones de Estado
- **Integrado correctamente:** El frontend consume el endpoint con el método, ruta y DTOs alineados al backend real.
- **Integrado con contrato incorrecto:** El frontend consume el endpoint pero con nombres de campos, tipos o body no conformes con el backend.
- **Parcial:** Existe integración en servicio pero no en UI completa, o la vista carece de alguno de los 4 estados.
- **No integrado:** Endpoint existente en backend pero no consumido actualmente por ningún servicio frontend.
- **Solo acción/modal:** No constituye una página independiente; se ejecuta desde un modal o acción dentro de otra pantalla.
- **Sin UI requerida:** Endpoint de infraestructura o interno sin vista de usuario final dedicada.
- **Bloqueado por dependencia:** Requiere una funcionalidad previa inexistente o carece de endpoint complementario en backend (`BRECHA FRONTEND ↔ BACKEND`).
